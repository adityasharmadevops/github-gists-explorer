1. The task in ordinary words

Build a small service that asks GitHub for somebody's publicly shared snippets. The person supplies a username, such as octocat. Your service asks GitHub for the data and sends it back. Then prove the behavior with automated checks and package the service so someone else can run it using Docker.

A Gist is a small collection of files. An API is a program's way of asking another program for information. A request is the question; a response is the answer. JSON is a text format containing lists, objects and values. An HTTP status summarizes whether the request succeeded. A port, here 8080, is the numbered entry point where the server listens.

2. Follow one request from beginning to end

  1. A caller requests http://localhost:8080/octocat.
  2. Gunicorn receives the HTTP request and passes it to the Flask application.
  3. Flask matches /<username> and calls get_gists("octocat").
  4. The route asks the shared GitHubClient object to fetch the public Gists.
  5. The client validates the username and opens a session owned by this lookup.
  6. It requests https://api.github.com/users/octocat/gists, checks the status, converts JSON into Python data, and keeps public entries.
  7. If GitHub reports another page, the client repeats using the same endpoint and connection pool. It applies page/time limits.
  8. The client returns one Python list. Flask converts the list into a JSON HTTP response.
  9. If something fails, a safe GitHubError becomes a deliberate HTTP status and message.
  10. The application logs the result and duration. Session/response context managers clean up their resources.

For the readable page, the same client supplies data. A separate helper selects display fields, then Jinja renders the HTML. The API's original fields are preserved.

Stages separate responsibilities. base supplies Python; dependencies installs libraries; test checks the application; runtime selects only the files needed to serve requests. Copying application files from test makes a normal release build depend on successful tests.
